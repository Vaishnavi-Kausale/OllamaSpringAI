## ⚡ SpringAI Ollama RAG Assistant

💡 AI-powered document assistant that lets you chat with your data.  
Built using Spring Boot + Spring AI + Ollama + React.

---

## 🧠 What it does

- 💬 Chat with PDFs & documents  
- 📚 Retrieves relevant context using RAG (Retrieval Augmented Generation)  
- 🤖 Uses local LLMs via Ollama (no external API dependency)  
- 🎯 Provides context-aware, grounded answers from your data  

---

## 🛠 Tech Stack

- ☕ Spring Boot  
- 🧠 Spring AI  
- 🦙 Ollama (Llama3 / Mistral)  
- ⚛️ React  
- 📦 Vector Store (pgvector / in-memory)  

---

## 🚀 Why this project

Built to demonstrate how LLMs can be integrated into real-world backend systems using the Java ecosystem — turning raw documents into a smart, searchable knowledge assistant.

---

## 🔥 Outcome

A simple but powerful AI system that works like a **private ChatGPT for your documents**.
